# scripts/ci-local-map.txt - local database requirements for scripts/ci-local.py.
#
# In CI every live suite sees the job's service: host `postgres`, port 5432 and
# the service's own database name, which each suite guard admits through its CI
# arm. Locally the database is on 127.0.0.1, so a suite is admitted only through
# its LOCAL arm, and that arm usually asks for a database NAME that looks
# disposable - some of them for one exact name. This file names those guards.
# ci-local.py finds every file a step reaches (npm scripts, the test files they
# name, the scripts a step runs and the files those name) and, before the step,
# renames the job database to the one name every reached guard admits.
# `python3 scripts/ci-local.py map` prints the resulting step list;
# `python3 scripts/ci-local.py check` fails when a line here matches nothing, or
# when a reached guard names a database this file does not cover.
#
# default <name>     the job database's name when no special guard applies. It
#                    must satisfy the generic local arm below.
# generic <regex>    the local arm most live suites share.
# require <id> name=<local name> db=<regex> sig=<regex>
#                    a reached file whose text matches sig admits only a loopback
#                    database whose whole name matches db; name is the one used.
# cionly <id> sig=<regex> note=<text>
#                    a reached file that admits the CI service and no loopback
#                    database the step's own arguments allow; the step is recorded
#                    env-unmet with the note instead of failing for that reason.
# known <literal> <why>
#                    a database-name literal in a guard that needs no line above.
