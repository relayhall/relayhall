# Name-reservation packages

These minimal packages reserved the RelayHall name at version `0.0.1` on npm,
PyPI, and crates.io before the public repository opened. They do not contain the
RelayHall server, client, SDK, or MCP implementation.

The source is retained here for provenance and future package handoff. Generated
archives, build directories, registry credentials, and publication tokens are
intentionally excluded. Publishing a later package version requires a separate
release decision and registry-specific review.

- `npm/` — CommonJS reservation package
- `pypi/` — Python reservation package
- `crates/` — Rust reservation crate

Project: https://relayhall.com · https://github.com/relayhall
